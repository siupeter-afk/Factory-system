# fable-mode

A Claude skill that enforces staged execution discipline on complex tasks: a written
stage plan, parallel delegation where the runtime supports it, a failable verification
check at each stage, and a skeptical self-review before delivery.

It does not change the underlying model's capability — it imposes procedural structure
and reinforces good reasoning habits. Use it for tasks spanning multiple files, multiple
sources, or multiple sessions. Skip it for simple, single-pass tasks.

See `SKILL.md` for the full skill definition and `EXAMPLE.md` for worked
before/after examples showing how the verification step catches errors that a
one-shot attempt would ship.

Source: https://github.com/mrtooher/fable-mode
